# f1-driver-stats-dashboard
Interactive Formula 1 driver standings dashboard built with Python and HTML.
## 📸 Overview

The dashboard provides a visual overview of Formula 1 driver standings, featuring driver cards, championship points, team information, and a bar chart for comparing the top drivers.

## Features

- Driver championship standings
- Visual comparison of driver points using a bar chart
- Driver cards displaying names, teams, numbers, and nationalities
- Race wins and championship points statistics
- Dark-themed user interface inspired by Formula 1
- Web interface powered by Flask

## 🛠️ Technologies Used

- Python
- Flask
- HTML5
- CSS3
- JavaScript

## Installation and Setup

### 1. Clone the repository

    git clone https://github.com/1232123903/f1-driver-stats-dashboard.git

### 2. Navigate to the project directory

    cd f1-driver-stats-dashboard

### 3. Create a virtual environment (optional but recommended)

    python -m venv venv

Activate it:

Windows:

    venv\Scripts\activate

macOS/Linux:

    source venv/bin/activate

### 4. Install dependencies

    pip install -r requirements.txt

### 5. Run the application

    python app.py

Open your browser and visit:

    http://127.0.0.1:5000/
